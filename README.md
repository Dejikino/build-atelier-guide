# Build Atelier — User Guide & Support

This repository contains the English and Japanese user guides and the public issue tracker for Build Atelier.

このリポジトリではBuild Atelierの日英説明書と問い合わせ窓口を提供します。

## User guide / 説明書

Read the [English guide](https://dejikino.github.io/build-atelier-guide/index-en.html).

[日本語の説明書](https://dejikino.github.io/build-atelier-guide/index-ja.html)をご覧ください。

## Support / お問い合わせ

Open the [issue tracker](https://github.com/Dejikino/build-atelier-guide/issues) for bug reports, usage questions, and feature requests. Japanese and English are welcome. A GitHub account is required to post. Reports and replies are public.

[問い合わせ窓口](https://github.com/Dejikino/build-atelier-guide/issues)から不具合・使い方の質問・機能要望を投稿できます。日本語・英語で受け付けます。投稿にはGitHubアカウントが必要です。投稿と返信は公開されます。

Please remove personal information, server addresses, and credentials from logs before posting. A full world download is not required for an initial report.

ログを添付する前に個人情報・サーバーアドレス・認証情報を取り除いてください。最初の報告でワールド全体を添付する必要はありません。
